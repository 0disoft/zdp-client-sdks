# v0.18.0에서 v0.19.0으로 이전

## 호환성 중단 변경

`core.auth.registrations.create()`에 API 계약의 필수 입력 `minimum_age_confirmed: boolean`과 `age_policy_ref: string`이 추가된다. 기존 세 필드만 전달하는 호출은 전송 전에 거부된다. 가입 화면에서 이용자의 최소 연령 확인을 받고, Core 정책 확인 흐름에서 받은 정책 참조를 함께 전달해야 한다. SDK는 확인값을 자동으로 채우거나 정책 참조를 발급하지 않는다. 서버가 해당 입력을 처리하는 배포를 확인한 뒤 소비 앱의 가입 요청을 변경한다.

## 계정 선택 정보

`core.account.preferences.get()`은 출생연도가 없는 상태를 `null`로, 연령 인증 여부를 항상 `false`로 보존한다. `core.account.preferences.update()`는 `{ birth_year, interests }`를 원자적으로 교체하며 성공 응답은 204와 `undefined`다. 저장한 값을 다시 표시할 때 조회 operation을 호출한다.

선택 정보를 저장할 때 호출자가 받은 동의를 확인하고 호출별 `headers`에 `x-zdp-profile-consent: account-optional-profile-v1`을 명시한다. 두 값을 비우는 요청에는 이 헤더가 필요하지 않다. SDK는 동의를 부여하거나 기본 헤더로 주입하지 않으며, 최종 검증은 Core가 수행한다. 변경 호출에는 기존과 같이 멱등 요청 키가 필요하다.

이 변경은 API 계약 `c8dfab7949b4b0fc41e6e6cd43a0a0b018eb6f8f`를 소비하는 로컬 SDK 변경이다. 각 operation의 실제 서버 활성화와 패키지 게시 상태는 별도로 확인한다.

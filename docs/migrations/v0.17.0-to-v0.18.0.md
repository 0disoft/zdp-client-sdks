# SDK migration v0.17.0 to v0.18.0

## Account settings overview nested models

`AccountSettingsOverviewGetResponse`의 중첩 값이 범용 `ZdpJsonObject`에서 다음 명시적 읽기 전용 interface로 바뀌었다.

- `AccountSettingsOverviewAccount`
- `AccountSettingsOverviewWorkspace`
- `AccountSettingsOverviewSession`
- `AccountSettingsOverviewConnectedProduct`
- `AccountSettingsOverviewNotificationPreference`

응답을 그대로 렌더링하는 코드는 변경할 필요가 없다. 중첩 값을 `ZdpJsonObject` 변수나 범용 record helper에 대입하던 소비자는 새 interface를 직접 받도록 타입을 바꾼다.

```ts
import type {
  AccountSettingsOverviewConnectedProduct,
  AccountSettingsOverviewGetResponse
} from 'zdp-client-sdks';

function connectedProducts(
  overview: AccountSettingsOverviewGetResponse
): readonly AccountSettingsOverviewConnectedProduct[] {
  return overview.connected_products.filter(
    (product) => product.connection_state === 'connected'
  );
}
```

`connection_state`와 notification `state`는 API 계약의 안정 enum으로 좁혀진다. 알 수 없는 값을 type cast로 허용하지 말고 protocol drift로 처리한다.

런타임 wire 검증은 기존 JSON object 경계를 유지한다. 이 버전은 요청 형식, endpoint, 인증 또는 응답 JSON을 바꾸지 않는다.
